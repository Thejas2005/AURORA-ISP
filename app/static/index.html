Input & processing

Standard Bayer RAW uses the Bayer ISP. Other camera RAW layouts are decoded to RGB when LibRaw supports them, then use RGB enhancement. PNG/JPG/TIFF use RGB enhancement.
Rendered images and LibRaw-supported camera RAW references are decoded to RGB for metric calculation only. The reference is never processed or enhanced. Dimensions must match the rendered output.
